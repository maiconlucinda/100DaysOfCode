# 100 Days of Code

This repository contains my daily coding projects and exercises, organized into individual folders (`Day001` through `Day100`). Each folder holds the code, notes, and resources for that specific day's project.

The goal of this challenge is to build consistent coding habits while progressively working through a wide range of topics, including Python fundamentals, automation, web scraping, APIs, data analysis, web development (Flask), databases, and more.

## Structure

```
100DaysofCode/
├── Day001/
├── Day002/
├── Day003/
...
└── Day100/
```

Each `DayXXX` folder contains the source code and any supporting files for that day's project.
